LensWhisper Desktop — Local Server

Local Server is a way to run LensWhisper's image analysis on a computer you own, on your own home network, instead of sending photos to our cloud servers.

Why use it?

  • Private. Your photos never leave your home network.
  • Free. No credits, no limits — it runs entirely on your own computer.
  • No cloud wait. Once it's running, there's no round trip to a server you don't control.

Once the desktop app is running on a computer on your Wi-Fi network, the LensWhisper phone app finds it automatically — just select Local Server as your model.

Early access note: a ready-to-run installer isn't published yet. For now, setting this up means building and running the companion app from source, below. This page will be updated with a one-click installer without changing this link, so it's safe to bookmark or share.

Requirements

  • Windows, macOS, or Linux computer on the same Wi-Fi network as your phone
  • A Java 17+ runtime (JDK)
  • ~500 MB–3 GB free disk space, depending on which AI model you choose

Setup

  1. Get the desktop/ project from the LensWhisper source repository.
  2. Open a terminal in that folder and run: 
    ./gradlew run
    (on Windows: gradlew.bat run)
  3. A control panel opens in your browser. Pick a model, download it, choose CPU or GPU, and press Start server.
  4. On your phone, open LensWhisper, select Local Server as the model — it finds your computer automatically as long as both are on the same Wi-Fi network.

See the project's desktop/README.md for full details, troubleshooting, and GPU setup.
