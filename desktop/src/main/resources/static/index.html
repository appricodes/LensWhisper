3. Thinking budget

Reasoning models (e.g. Gemma 4) think internally before writing their answer. Too low a budget can cut that off before an answer is produced at all; too high wastes time. Only applies to models whose template supports reasoning — ignored by others.

4. Password (required)

Checking…

Required — the server can't start without one. Every analysis request and response between the phone and this computer is encrypted using it, so only a phone with the matching password entered in Settings can read or send anything. Only the password's token is ever stored here or on the phone — never the password itself — but that token doubles as the encryption key, so it's just as sensitive as the password. Removing it requires stopping the server first.
